# 1일차 8교시: 앱 만들어 보기 (오늘 점심 뭐 먹지?)

[전체 일정으로](../README.md)

7교시까지 마치고 시간이 남으면 만드는 앱입니다. 버튼을 누르면 점심 메뉴를 하나 뽑아 주는 앱입니다. 파일은 하나이고, 화면 모양은 만들어져 있습니다. 파일 안의 [1], [2], [3] 세 군데를 채웁니다. 힌트는 바로 아래 줄에 적혀 있습니다. `day1_step03_lifecycle`와 같은 프로젝트에 이 앱의 뼈대를 더했습니다. 정답은 [day1_extra_answer](../day1_extra_answer) 폴더에 따로 있습니다.

## 요구사항

1. 뽑기!를 누르면 메뉴 목록(`lunchMenus`)에서 하나를 골라 크게 보여 줍니다
2. 몇 번 뽑았는지 보여 주고, 아래에 뽑은 순서대로 기록이 쌓입니다
3. 처음부터를 누르면 기록이 비워집니다
4. 더 해 보기: 같은 메뉴가 연달아 나오지 않게 합니다

## 만드는 방법

1. Android Studio에서 File > Open으로 이 폴더를 열고 Run 합니다.
2. 에뮬레이터의 앱 목록(홈 화면을 위로 밀어 올림)에서 아래 표의 연습 아이콘을 누릅니다.
3. 연습 파일을 고치고 다시 Run 합니다. 막히면 [1] [2] [3] 바로 아래의 힌트를 보고, 그래도 안 되면 `day1_extra_answer` 폴더의 정답 파일을 봅니다.

| 아이콘 | 연습 파일 | 정답 파일 |
|---|---|---|
| 점심 뽑기 연습 | `practice/LunchPick.kt` | `practice/LunchPickAnswer.kt` |
