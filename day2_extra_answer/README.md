# 2일차 8교시 정답: 반응 속도 게임

[전체 일정으로](../README.md) | 연습 틀: [day2_extra_practice](../day2_extra_practice)

`day2_extra_practice`에서 직접 만들어 본 뒤에 여는 정답 프로젝트입니다. Android Studio에서 이 폴더를 열고 Run 한 다음, 에뮬레이터의 앱 목록에서 "정답"이 붙은 아이콘을 누릅니다. 연습 틀과 앱 ID가 같아서, 설치하면 에뮬레이터의 연습 앱이 이 앱으로 바뀝니다.

| 파일 | 내용 |
|---|---|
| `practice/ReactionAnswer.kt` | ViewModel. 기다리기(코루틴), 일찍 누르면 취소, 걸린 시간 재기 |
| `practice/ReactionScreen.kt` | 상태와 화면. 연습 틀과 같음 |
