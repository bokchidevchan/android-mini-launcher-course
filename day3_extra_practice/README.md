# 3일차 8교시: 앱 룰렛 만들기 (뼈대)

3일차 8교시 | [전체 일정으로](../README.md) | 완성: [day3_extra_answer](../day3_extra_answer)

돌리기를 누르면 설치된 앱 이름이 빠르게 바뀌다가 하나에서 멈추고, "이 앱 열기"를 누르면 그 앱이 열리는 앱입니다. 화면 모양은 만들어져 있습니다.

File > Open으로 이 폴더를 열고 Run 하면 앱 룰렛 화면이 바로 뜹니다. 아래 [1]부터 차례로 채우고, 채울 때마다 Run 합니다. 채우는 곳은 `practice/AppRoulette.kt` 하나이고, 파일 안에 `[1] 여기를 채웁니다`처럼 자리가 표시되어 있습니다.

전체 흐름은 이렇습니다.

```
화면이 뜸      → [1] 설치된 앱 목록을 읽어 apps 에 넣음
돌리기를 누름  → [2] current 를 아무 앱으로 15번 바꾸고 멈춤
이 앱 열기     → [3] current 앱을 엶
```

파일 위쪽에 화면에서 쓰는 값이 있습니다.
- `apps`: 설치된 앱 목록
- `current`: 지금 화면에 보이는 앱. 처음에는 비어 있음(`null`)
- `spinning`: 돌아가는 중인지. `true`이면 버튼이 눌리지 않음
- `scope`: 이 화면에서 코루틴을 시작하는 곳

## [1] 화면이 뜰 때 설치된 앱 목록 읽기

**하는 일**: 화면이 처음 뜰 때 한 번, 설치된 앱 목록을 읽어 `apps`에 넣습니다.

**채울 곳**: `LaunchedEffect(Unit) { }` 안의 `[1] 여기를 채웁니다` 아래. 한 줄입니다.

**힌트**: 오늘 1교시에 본 `InstalledAppRepository`의 `loadApps()`로 읽습니다. 만들 때 `context.applicationContext`를 넘깁니다.

**확인**: "설치된 앱 ○○개 가운데 하나"에 숫자가 나오고 돌리기 버튼이 눌립니다.

## [2] 돌리기

**하는 일**: 코루틴으로 `current`를 아무 앱으로 15번 바꾸고 멈춥니다. 한 번 바꿀 때마다 0.08초 쉽니다. 도는 동안 `spinning`은 `true`입니다.

**채울 곳**: 돌리기 버튼의 `onClick = { }` 안의 `[2] 여기를 채웁니다` 아래.

```kotlin
scope.launch {
    spinning = true
    repeat(15) {                  // 15번 반복
        current = ______________  // ① 아무 앱 하나
        ______________            // ② 0.08초 쉼
    }
    spinning = false
}
```

**힌트**
- ① 목록에서 아무거나 하나를 고르는 함수는 `random()`입니다.
- ② 코루틴의 쉬기 함수입니다. 1000이 1초입니다.

**확인**: 돌리기를 누르면 앱 이름이 빠르게 바뀌다가 멈춥니다. 도는 동안 버튼이 "돌아가는 중"으로 바뀌고 눌리지 않습니다.

## [3] 이 앱 열기

**하는 일**: 지금 보이는 앱(`current`)을 엽니다.

**채울 곳**: "이 앱 열기" 버튼의 `onClick = { }` 안의 `[3] 여기를 채웁니다` 아래. 한 줄입니다.

**힌트**
- 오늘 2교시에 본 `launchApp(context, 앱)`을 씁니다.
- `current`는 비어 있을 수 있어서 그대로 넘기면 빨간 줄이 생깁니다. `current?.let { }` 안에서는 `it`이 비어 있지 않은 앱입니다.

**확인**: 멈춘 뒤 "이 앱 열기"를 누르면 그 앱이 열립니다.
