# 3일차 8교시: 앱 만들어 보기 (앱 룰렛)

[전체 일정으로](../README.md)

7교시까지 마치고 시간이 남으면 만드는 앱입니다. 설치된 앱 가운데 하나를 룰렛처럼 뽑아서 열어 주는 앱입니다. 채우는 파일은 하나이고, 화면 모양은 만들어져 있습니다. 파일 안의 [1], [2], [3] 세 군데를 채웁니다. 힌트는 바로 아래 줄에 적혀 있습니다. 이 폴더에는 이 앱의 코드만 들어 있습니다. 정답은 [day3_extra_answer](../day3_extra_answer) 폴더에 따로 있습니다.

## 요구사항

1. 화면이 뜨면 설치된 앱이 몇 개인지 보여 줍니다
2. 돌리기를 누르면 앱 이름이 빠르게 바뀌다가 하나에서 멈춥니다
3. 돌아가는 동안에는 버튼이 눌리지 않습니다
4. 이 앱 열기를 누르면 멈춘 앱이 열립니다

## 만드는 방법

1. Android Studio에서 File > Open으로 이 폴더를 열고 Run 합니다. 앱이 바로 뜹니다.
2. 연습 파일을 고치고 다시 Run 합니다. 막히면 [1] [2] [3] 바로 아래의 힌트를 보고, 그래도 안 되면 `day3_extra_answer` 폴더의 정답 파일을 봅니다.

| 앱 | 연습 파일 (이 폴더) | 정답 파일 (정답 폴더) |
|---|---|---|
| 앱 룰렛 | `practice/AppRoulette.kt` | `practice/AppRouletteAnswer.kt` |
