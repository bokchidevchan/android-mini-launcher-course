# 2일차 8교시: 앱 만들어 보기 (반응 속도 게임)

[전체 일정으로](../README.md)

7교시까지 마치고 시간이 남으면 만드는 앱입니다. 화면이 초록색으로 바뀌는 순간 얼마나 빨리 누르는지 재는 게임입니다. 기다리는 일은 코루틴의 delay가 맡습니다. 채우는 파일은 하나이고, 화면 모양은 만들어져 있습니다. 파일 안의 [1], [2], [3] 세 군데를 채웁니다. 힌트는 바로 아래 줄에 적혀 있습니다. 이 폴더에는 이 앱의 코드만 들어 있습니다. 정답은 [day2_extra_answer](../day2_extra_answer) 폴더에 따로 있습니다.

## 요구사항

1. 화면을 누르면 빨간색이 되고, 1~4초 사이 무작위 시간이 지난 뒤 초록색으로 바뀝니다
2. 초록색일 때 누르면 걸린 시간(ms)을 보여 줍니다
3. 초록색이 되기 전에 누르면 "너무 빨랐어요"를 보여 주고, 그 뒤로 초록색으로 바뀌면 안 됩니다
4. 결과 화면을 누르면 다시 시작합니다

## 만드는 방법

1. Android Studio에서 File > Open으로 이 폴더를 열고 Run 합니다. 앱이 바로 뜹니다.
2. 연습 파일을 고치고 다시 Run 합니다. 막히면 [1] [2] [3] 바로 아래의 힌트를 보고, 그래도 안 되면 `day2_extra_answer` 폴더의 정답 파일을 봅니다.

| 앱 | 연습 파일 (이 폴더) | 정답 파일 (정답 폴더) |
|---|---|---|
| 반응 속도 게임 | `practice/ReactionGame.kt` | `practice/ReactionGameAnswer.kt` |
