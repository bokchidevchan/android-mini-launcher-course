# 2일차 8교시: 반응 속도 게임 만들기 (뼈대)

2일차 8교시 | [전체 일정으로](../README.md) | 완성: [day2_extra_answer](../day2_extra_answer)

화면을 누르면 빨간색이 되고, 잠시 뒤 초록색으로 바뀝니다. 초록색이 된 순간부터 누를 때까지 걸린 시간을 보여 주는 게임입니다. 화면 모양은 만들어져 있습니다.

File > Open으로 이 폴더를 열고 Run 하면 게임 화면이 바로 뜹니다. 아래 [1]부터 차례로 채우고, 채울 때마다 Run 합니다. 채우는 곳은 `practice/ReactionGame.kt` 하나이고, 파일 안에 `[1] 여기를 채웁니다`처럼 자리가 표시되어 있습니다.

전체 흐름은 이렇습니다.

```
처음 화면을 누름 → [1] 빨간색, 1~4초 뒤 초록색
초록색 전에 누름 → [2] "너무 빨랐어요"
초록색에 누름   → [3] 걸린 시간(ms)
```

파일 위쪽에 화면에서 쓰는 값이 있습니다.
- `screen`: 지금 화면. "처음", "기다림", "지금", "결과", "너무 빠름" 가운데 하나이고, 바꾸면 색과 글자가 따라 바뀝니다
- `goTime`: 초록색이 된 시각
- `result`: 걸린 시간
- `waiting`: 초록색을 기다리는 코루틴
- `scope`: 이 화면에서 코루틴을 시작하는 곳

화면을 누르면 `clickable { }` 안의 `when (screen)`이 지금 화면에 맞는 칸을 실행합니다. [1] [2] [3]은 이 칸들 안에 있습니다.

## [1] 누르면 기다렸다가 초록색으로 바꾸기

**하는 일**: 화면을 빨간색("기다림")으로 바꾸고, 코루틴으로 1~4초 쉰 뒤 초록색("지금")으로 바꿉니다.

**채울 곳**: `else -> { }` 안의 `[1] 여기를 채웁니다` 아래.

```kotlin
screen = "기다림"
waiting = scope.launch {          // 코루틴 시작. 나중에 취소하려고 waiting 에 담아 둠
    ______________                // ① 1~4초 쉼
    goTime = ______________       // ② 지금 시각을 적어 둠
    screen = "지금"
}
```

**힌트**
- ① 오늘 배운 코루틴의 쉬기 함수에 `Random.nextLong(1000, 4000)`을 넘기면 1~4초 사이 아무 시간만큼 쉽니다.
- ② 지금 시각(ms)은 `System.currentTimeMillis()`입니다.

**확인**: 화면을 누르면 빨간색이 되고, 잠시 뒤 초록색 "지금!"이 됩니다.

## [2] 너무 일찍 누르면 멈추기

**하는 일**: 빨간색일 때 누르면 기다리던 코루틴을 취소하고 "너무 빨랐어요"를 보여 줍니다. 취소하지 않으면 잠시 뒤 초록색으로 또 바뀝니다.

**채울 곳**: `"기다림" -> { }` 안의 `[2] 여기를 채웁니다` 아래. 두 줄입니다.

**힌트**
- 코루틴을 멈추는 함수는 오늘 배운 `cancel()`입니다. `waiting`은 비어 있을 수 있어서 `?.`를 붙입니다.
- 그다음 `screen`을 "너무 빠름"으로 바꿉니다.

**확인**: 빨간색일 때 누르면 "너무 빨랐어요"가 뜨고, 기다려도 초록색으로 바뀌지 않습니다.

## [3] 제때 누르면 걸린 시간 보여 주기

**하는 일**: 초록색일 때 누르면 걸린 시간을 `result`에 넣고 결과 화면으로 바꿉니다.

**채울 곳**: `"지금" -> { }` 안의 `[3] 여기를 채웁니다` 아래. 두 줄입니다.

**힌트**
- 걸린 시간은 지금 시각에서 `goTime`을 뺀 값입니다.
- 그다음 `screen`을 "결과"로 바꿉니다.

**확인**: 초록색일 때 누르면 "250ms"처럼 걸린 시간이 뜹니다. 한 번 더 누르면 다시 시작합니다.
