# 2일차 시간이 남으면: 실습 문제

[전체 일정으로](../README.md)

2일차 수업이 일찍 끝났을 때 푸는 문제입니다. `day2_step06_service`와 같은 앱에 문제 파일만 더했습니다.

## 푸는 방법

1. Android Studio에서 File > Open으로 이 폴더를 엽니다.
2. `app/src/main/java/com/example/minilauncher/practice/Day2Extra.kt`를 엽니다.
3. `TODO`가 적힌 줄을 고치고 Run 합니다.
4. Logcat 검색창에 `tag:Extra`를 넣습니다. 앱이 뜨고 5초쯤 뒤에 문제마다 O, X가 찍힙니다.

```
문제 1: O
문제 2: X  나온 값 [], 기대한 값 [SETTINGS, CAMERA, ...]
```

## 파일

| 파일 | 내용 |
|---|---|
| `practice/Day2Extra.kt` | 문제. 여기만 고칩니다 |
| `practice/Day2ExtraAnswers.kt` | 정답. 먼저 풀어 보고 엽니다 |
| `practice/Day2ExtraCheck.kt` | 채점하는 코드. 고치지 않습니다 |
