# 홈 화면 위젯 (완성 코드, 5교시 설명용)

3일차 14:00~ | [전체 일정으로](../README.md) | 뼈대(선택): [day3_task2_widget_practice](../day3_task2_widget_practice)

수업에서는 이 코드로 위젯이 어떻게 동작하는지 설명만 하고, 직접 만드는 실습은 하지 않습니다. 궁금하면 수업 뒤에 Run 해 보세요.

`practice/MiniWidget.kt`의 [1] [2] [3]을 채운 완성본입니다. 위젯만 들어 있는 작은 앱(이름 "위젯 연습")입니다.

1. File > Open으로 이 폴더를 열고 Run 합니다.
2. 홈 앱이 Pixel Launcher인지 확인합니다.
3. 홈 화면 빈 곳을 길게 누름 > Widgets > 위젯 연습 > Add.
4. "새로고침"을 누르면 시각과 앱 개수가 바뀌고, 제목을 누르면 안내 화면이 열립니다. Logcat 검색칸에 `tag:Widget`을 넣으면 갱신할 때마다 한 줄씩 찍힙니다.
