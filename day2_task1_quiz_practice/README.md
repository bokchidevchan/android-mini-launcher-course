# 오전 과제: 복습 퀴즈 앱 만들기 (뼈대)

2일차 11:00~ | [전체 일정으로](../README.md) | 완성: [day2_task1_quiz_answer](../day2_task1_quiz_answer)

버튼을 누르면 인터넷에서 문제 목록을 받아 와 하나를 보여 주는 앱입니다. 문제는 어제와 오늘 배운 내용입니다. 이 폴더는 뼈대 프로젝트입니다. 화면과 상태는 만들어져 있고, 받아 오는 부분만 채웁니다.

## 만드는 방법

1. Android Studio에서 File > Open으로 이 폴더를 엽니다.
2. `practice/QuizApp.kt`를 열고 [1], [2], [3]을 차례로 채웁니다. 채울 코드는 번호 아래 주석에 있습니다. 주석 기호(//)를 떼고 쓰면 됩니다.
3. 하나 채울 때마다 Run 하고, 에뮬레이터의 앱 목록에서 "복습 퀴즈" 아이콘을 눌러 확인합니다.
4. 마지막으로 `practice/FreezeFix_My.kt`를 열고 표시된 자리의 한 줄을 안내대로 바꿉니다([4]). 앱 목록의 멈춤 고치기 아이콘으로 확인합니다.

| 단계 | 채우는 것 | Run 해서 확인 |
|---|---|---|
| [1] | `load` 안에서 상태를 Success로 바꾸는 한 줄 | 버튼을 누르면 문제가 뜨고 정답 보기가 됩니다 |
| [2] | `fetchQuizzes`: IO 스레드에서 주소에 연결해 글자를 읽고 목록으로 바꿉니다 | 화면은 아직 그대로입니다 |
| [3] | `load`: 받아 오는 중으로 바꾸고, 코루틴에서 받아 와 상태에 넣습니다. 실패는 `try`, `catch`로 잡습니다 | 버튼을 누르면 받아 온 문제가 나옵니다 |
| [4] | `practice/FreezeFix_My.kt`: 3초 동안 멈추는 화면을 코루틴으로 고칩니다 | 3초 걸리는 일을 눌러도 화면이 안 멈춥니다 |

| 파일 | 내용 |
|---|---|
| `practice/QuizApp.kt` | 채우는 파일. 받아 오는 함수와 ViewModel |
| `practice/QuizScreen.kt` | 그대로 쓰는 파일. 주소, 화면 상태, 화면 |
| `practice/FreezeFix_My.kt` | [4]에서 고치는 파일. 3초 동안 멈추는 화면 |

받아 오는 주소는 이 저장소의 `docs/api/quiz.json`입니다.
