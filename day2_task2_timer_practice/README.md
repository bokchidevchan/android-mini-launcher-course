# 오후 과제: 컵라면 타이머 만들기 (뼈대)

2일차 16:00~ | [전체 일정으로](../README.md) | 완성: [day2_task2_timer_answer](../day2_task2_timer_answer)

10초 (맛보기) 버튼을 누르고 홈으로 나가도 알림에서 남은 시간이 계속 줄어드는 앱입니다. 화면이 아니라 Foreground Service가 시간을 셉니다. 이 폴더는 뼈대 프로젝트이고, 이 과제의 코드만 들어 있습니다. 화면과 알림은 만들어져 있고, Service 안만 채웁니다.

## 만드는 방법

1. Android Studio에서 File > Open으로 이 폴더를 엽니다.
2. `practice/RamenTimer.kt`를 열고 [1], [2], [3]을 차례로 채웁니다. 채울 코드는 번호 아래 주석에 있습니다. 주석 기호(//)를 떼고 쓰면 됩니다.
3. 하나 채울 때마다 Run 합니다. 컵라면 타이머 화면이 바로 뜹니다. [1]을 채운 뒤에 10초 (맛보기) 버튼을 누릅니다.

| 단계 | 채우는 것 | Run 해서 확인 |
|---|---|---|
| [1] | 알림 채널을 만들고 `startForeground`로 알림과 함께 올립니다 | 10초 (맛보기)를 누르면 알림이 뜹니다. 시간은 아직 안 줄어듭니다 |
| [2] | 코루틴에서 1초마다 남은 시간을 줄이고 알림을 고칩니다. 다 세면 알림을 바꾸고 `stopSelf` | 화면과 알림의 숫자가 줄어듭니다. 홈으로 나가도 계속 줄고, 끝나면 "다 익었어요" |
| [3] | `onDestroy`에서 `scope.cancel()` | 보이는 차이는 없습니다. Service가 끝난 뒤 코루틴이 남는 것을 막습니다 |

| 파일 | 내용 |
|---|---|
| `practice/RamenTimer.kt` | 채우는 파일. Service와 Activity |
| `practice/RamenTimerScreen.kt` | 그대로 쓰는 파일. 남은 시간, 알림, 화면 |
